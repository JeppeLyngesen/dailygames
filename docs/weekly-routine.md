# The owner's 5-hour week

Start a Claude Code session in this repo and work through it in order.

| Time | What | How |
|---|---|---|
| 30 min | **Board meeting** | "Use the ceo agent to run the weekly review." Answer its yes/no decisions. |
| 2.5 h | **Build** | Pick the top backlog item. Let Claude implement it on a branch, then "use the qa-reviewer agent on this diff". Read the code: you're learning too. Merge → it deploys automatically. |
| 1 h | **Content / growth** | Review ONE draft from content-seo or growth. Add your own voice. Publish/post it yourself. |
| 30 min | **Numbers** | Paste Search Console + analytics + Ko-fi numbers; "use finance-analytics to update kpis.md". |
| 30 min | **Buffer** | User feedback, bugs, legal-compliance review if something new was added. |

Rule: if the week only has 2 hours, do the board meeting + one small build item. Consistency beats intensity.
